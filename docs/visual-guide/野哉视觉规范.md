# 野哉视觉规范

> 版本：v1  
> 整理方式：基于当前野哉小程序代码、文案、Logo 资源与页面样式反向提炼。  
> 用途：作为未来野哉相关页面、海报、活动物料、社群招募图、AI 生成素材的统一视觉上下文。

## 1. 文档定位

这份规范不是从零假设出来的品牌提案，而是对当前野哉线上产品中已经稳定出现的视觉信号做总结，并把它整理成一套可执行标准。

如果未来需要让设计师、AI 设计工具、活动策划、社媒运营共同产出素材，优先以这份文档为准，再根据具体场景做轻微偏移。

## 2. 野哉的视觉一句话

**野哉不是“旅游宣传风”，而是“在地田野感 + 编辑式叙事 + 土地肌理”的视觉系统。**

它要传达的不是热闹、攻略、打卡和度假，而是：

- 真实在场
- 靠近土地
- 靠近在那里生活的人
- 节奏缓下来之后才看得见的内容
- 有温度，但不甜腻
- 有气质，但不悬浮
- 有品牌感，但不能妨碍理解和转化

## 3. 视觉总纲

### 3.1 品牌气质关键词

- 在地
- 真实
- 旷野
- 慢
- 沉着
- 质朴
- 人文
- 纪录感
- 编辑感
- 温度
- 信任

### 3.2 核心审美方向

如果必须用设计方向来概括，野哉更接近下面这组组合，而不是常见的互联网旅行产品风格：

- 主方向：**Organic / Natural**
- 结构方向：**Editorial / Magazine**
- 局部性格：**Raw / Slightly Brutalist**

翻译成执行语言就是：

- 整体结构克制、留白充足、信息排布清楚
- 局部通过斜切、旋转、肌理、印刷感去打破“模板味”
- 不走精致奢华度假风，也不走年轻互联网潮流风
- 不做“高饱和蓝天 + 微笑游客 + 精致卡片 UI”的旅游产品既视感

### 3.3 视觉人格

可以把野哉理解成一个有明确偏好的品牌人格：

- 像一本关于土地、人物与路线的当代田野杂志
- 像一张有旧印刷感的招募海报
- 像一个认真做路线、也认真做内容的在地组织

而不是：

- 一个景点分销平台
- 一个网红打卡推荐账号
- 一个靠“治愈感滤镜”取胜的旅行品牌

## 4. 色彩系统

当前代码里最稳定的颜色集中在暖米色、赭红、焦橙、深褐文字这条线上。整体属于**土地色 / 纸张色 / 晒过太阳的色系**。

### 4.1 主色板

| 角色 | 色值 | 建议命名 | 用法 |
| --- | --- | --- | --- |
| 主背景色 | `#F2E6C9` | 暖米纸色 | 页面底、浅色画布、大面积底色 |
| 标题主文字 | `#2B241D` | 深土黑 | 主标题、重点正文、关键信息 |
| 次级文字 | `#6A5A4B` | 灰褐 | 摘要、说明、辅助信息 |
| 品牌主色 | `#993921` | 赭红 | 眉标、链接、强调、分割线、边框 |
| 动作强调色 | `#D15E14` | 焦橙 | 主按钮、可操作 CTA、选中状态 |
| 辅助棕色 | `#8A5A38` | 栗棕 | 标签、统计文字、弱强调 |
| 浅底补充色 | `#F9F4EC` | 温纸白 | 弹层、局部卡片、浅底内容区 |
| 深色按钮渐变 | `#9A6840` / `#7D5231` | 木棕渐变 | 会员、登录、偏质感场景 |

### 4.2 推荐配色比例

- 60% 到 70%：暖米纸色、灰白、浅纸色
- 15% 到 20%：深土黑、灰褐文字
- 10% 到 15%：赭红与焦橙
- 5% 以内：浅金、浅棕、半透明黑白作为层次辅助

### 4.3 色彩使用原则

- 不要用纯白做大面积底色，优先用偏暖、偏纸张的底色
- 不要用纯黑压页面，深色应更接近土黑、墨褐
- 红色不是喜庆红，而是**土壤感、印泥感、晒热后的赭红**
- 橙色不是互联网橙，而是更偏**烧陶、夕照、矿物**的焦橙

### 4.4 明确禁忌

- 禁止蓝紫、赛博紫、荧光粉、霓虹蓝
- 禁止高对比霓虹渐变
- 禁止冷白科技风背景
- 禁止“海岛度假蓝 + 高饱和橙”的传统旅游宣传配色

## 5. 字体系统

野哉的字体不是单一风格，而是一个很明确的三层结构：

### 5.1 标题字体

**首选气质：宋体系中文衬线**

- 推荐：`Songti SC`、`STSong`、同气质中文宋体
- 用途：页面主标题、海报主标题、文章标题、人物名、目的地名、栏目标题
- 气质：克制、文化感、人文、编辑感

执行建议：

- 标题不宜过黑，当前产品主标题多为 `500`
- 标题更适合较松的行高与少量字距，而不是紧密挤压
- 大标题适合 1.35 到 1.55 的行高，保持呼吸感

### 5.2 正文字体

**首选气质：清晰、稳定、不过度设计的中文无衬线**

- 当前实现以 `PingFang SC` 为主
- 用途：说明、摘要、表单、信息正文、辅助说明
- 要求：易读、干净、让位于内容，不喧宾夺主

### 5.3 引语字体

**只在“引语/诗句/片段”里使用楷体**

- 推荐：`KaiTi`、`STKaiti`
- 用途：引语、摘录、诗句、带有手写感的内容
- 注意：不要把楷体滥用到所有标题或正文，否则会过于复古、失去节制

### 5.4 英文与数字

- 英文字母尽量少量出现，出现时更像栏目标签或系统信息，而不是做主视觉主体
- 适合使用轻量无衬线，并配合稍大的字距
- 英文不要做“潮牌式夸张设计”

## 6. 版式与结构

### 6.1 整体结构原则

野哉的页面不是强视觉噪音型，而是**单列叙事式、编辑式的纵向结构**：

- 大图开场
- 大标题进入
- 说明文字留足呼吸
- 内容块之间用细分割线或较大间距切开
- 以“看重点，再决定要不要深入”为组织逻辑

### 6.2 布局特征

- 一列纵向为主
- 标题与说明采用明显层级差
- 栏目眉标用赭红小字距拉开
- 图片常用大圆角，但文字区块本身更克制
- 卡片不是悬浮厚阴影卡，而更接近“图 + 文 + 分割线”的轻容器

### 6.3 圆角、边线、阴影

当前产品中比较稳定的几组规则：

- 图片圆角：`24rpx` 左右
- 主按钮圆角：`12rpx`
- 胶囊标签 / 筛选器：`999rpx`
- 文本区块：多数不依赖大圆角，而是用底部分割线
- 分割线：品牌赭红的低透明度细线
- 阴影：极轻，仅在少数浮层、个人页卡片里使用

结论：

- **野哉的高级感来自留白、文字层级和材质感，不来自厚重阴影。**

### 6.4 版式语法

推荐把野哉的版式理解为：

- `眉标`：小、疏朗、赭红、字距拉开
- `主标题`：宋体、大字、稳重
- `摘要`：长行距、留白多、偏灰褐
- `分隔`：细线、浅纹理、留白，不靠大色块硬切

### 6.5 可用于海报/KV 的结构语言

当前首页第二屏和 Logo 气质说明了一件事：野哉允许局部“不那么规整”。

可复用的做法：

- 斜向或旋转的大色带
- 倾斜放置的 Logo 或字块
- 旧印刷、拓印、磨损感肌理
- 大面积空白 + 一处强视觉重心

但要注意：

- 这种“不规整”应出现在视觉重心区，而不是让整张物料失去阅读顺序

## 7. 图像与材质

### 7.1 图片选择原则

野哉适合的不是“旅游宣传片截图”，而是**纪录片式的在场图像**。

优先选择：

- 山地、河谷、草场、雨林、盐田、茶山、港口、村寨等土地场景
- 人与土地发生关系的瞬间
- 路线、劳作、观察、行走、停留、对话、手写记录
- 带天气、尘土、风、雾、阴影、材质细节的图像
- 人物不一定正脸，重点是“正在参与”

避免选择：

- 摆拍游客照
- 过度商业修图
- 过饱和蓝天草地
- 明显“打卡感”“出片感”的网红素材
- 一眼就是通用图库旅游封面

### 7.2 图片调性

- 略微降饱和
- 保留土地和空气感
- 暖调优先，但不能黄到脏
- 可以有雾、阴天、逆光、暮色，不必追求全都“亮”
- 比起“艳”，更重视“厚”

### 7.3 材质关键词

适合野哉的材质感包括：

- 纸张
- 印刷
- 拓印
- 颗粒
- 风化
- 土壤
- 纤维
- 手作
- 植物脉络

不适合的材质感包括：

- 金属科技
- 玻璃拟态
- 液态炫光
- 电商风高光塑料感

## 8. Logo、图形与品牌符号

### 8.1 Logo 气质

当前本地 Logo `miniprogram/images/splash-logo.png` 给出的信息很明确：

- Logo 不是精致小资路线，而是**有冲刷感、磨损感、印记感**
- 字形偏手工、偏雕版、偏拓印，而不是标准商业字标
- 颜色是赭红，而非纯黑或高纯度红

### 8.2 Logo 使用建议

- 优先放在暖白、纸白、浅米色背景上
- 允许小角度旋转，增强“现场感”和“印记感”
- 不建议缩得太小，否则磨损细节会丢失
- 不建议加描边、发光、渐变、投影
- 不建议被塞进常规互联网圆角卡片中心做“标准 logo 锁定”

### 8.3 可延展图形语言

从现有页面能稳定抽取出的辅助图形包括：

- 细分割线
- 斜向色带
- 叶片形收藏图标
- 单字 Glyph 装饰
- 轻颗粒、轻磨损、轻纸纹

这意味着未来物料可以有自己的“野哉图形系统”，但应遵守一个前提：

- 图形是辅助品牌气质，不是为了热闹而堆装饰

## 9. 组件语言

### 9.1 标题区

- 眉标：小号、赭红、字距明显拉开
- 标题：宋体大字
- 摘要：长行距、灰褐色

### 9.2 卡片

- 以内容为核心，不依赖厚底色与厚阴影
- 更多使用底部分割线，而不是完整封闭容器
- 图片可圆角，文本区保持简洁

### 9.3 标签

- 标签常为浅色半透明底 + 细边框
- 或直接纯文字，不做厚重彩色胶囊
- 颜色靠近栗棕、赭红、浅金

### 9.4 按钮

- 主按钮：焦橙底，可加极轻重复纹理
- 次按钮：暖米半透明底 + 赭红描边
- 文字按钮：赭红文字 + 下划线 / 底边线

### 9.5 导航与切换

- 选中态更适合用**下划线、底边、文字变色**
- 不适合用夸张实心高亮块

## 10. 文案气质

野哉的文案不是冷信息流，也不是鸡汤诗歌，而是**带画面感的事实性表达**。

### 10.1 文案语气

- 安静
- 具体
- 有画面
- 有感受，但不过分煽情
- 强调“节奏”“在地”“真实”“靠近”

### 10.2 常用表达域

适合反复出现的词：

- 在地
- 真实在场
- 节奏
- 路线
- 土地
- 人物
- 旅人
- 创作者
- 同行者
- 观察
- 记录
- 留白
- 靠近
- 山海

### 10.3 不适合的表达

- 小众秘境必打卡
- 爆款路线
- 出片圣地
- 说走就走
- 治愈一切
- 逃离城市
- 纯净天堂
- 极致松弛感
- 高级感拉满

### 10.4 文案策略分场景

#### 品牌页 / 海报 / 活动物料

可以更诗性、更留白，但必须落在土地、人、路线、节奏这些具体对象上。

#### 商品详情 / 交易页 / 报名页

要明显收缩故事性，优先让用户快速理解：

- 这是什么
- 适合谁
- 怎么报名
- 风险与规则
- 下一步是什么

也就是说：

- **品牌语气可以诗性**
- **交易信息必须直接**

## 11. 不同场景的应用建议

### 11.1 页面设计

- 优先用暖底 + 大图 + 宋体标题
- 用分割线和留白拉开区块
- 关键信息前置，避免长篇大论后才出现行动入口
- 品牌感主要通过字体、色彩、纹理和眉标实现

### 11.2 海报 / 主视觉 KV

- 以一张强在地图像做重心
- 配合赭红 Logo、宋体标题、少量斜向结构
- 可以加入纸纹、颗粒、旧印刷感
- 信息排版像文化活动海报，不像旅游促销广告

### 11.3 活动招募图 / 社群宣传图

- 标题更明确，副标题负责解释内容
- 视觉上保持野哉气质，但信息组织必须清楚
- 可以出现时间、地点、人数、报名方式等硬信息
- 不要为了“文艺”牺牲可读性

### 11.4 社媒封面 / 小红书类素材

- 保留品牌赭红与纸张感
- 封面文案不宜过满
- 一张图只传达一个主题，不要把全部卖点塞进去
- 人物图优先真实互动场景，而不是对镜微笑

## 12. 明确禁忌

下面这些做法一旦出现，基本就会偏离野哉：

- 高频使用纯白背景 + 鲜艳彩色按钮
- 大量渐变、发光、玻璃拟态
- 过分圆润的 SaaS 卡片风
- 蓝紫色、霓虹色、赛博感特效
- 旅游宣传册式大字报
- “美景 + 大 logo + 大促销文案”的电商旅行风
- 大量堆叠徽章、标签、角标
- 过多感叹号与煽动性口号
- 过满排版、没有呼吸空间
- 文案全是抽象抒情，没有具体对象

## 13. 给 AI 工具的直接上下文

下面这段可以直接作为图像生成、版式生成、页面设计 AI 的前置上下文：

```text
你正在为“野哉”设计页面/海报/活动素材。请遵守以下视觉规范：

品牌气质是“在地田野感 + 编辑式叙事 + 土地肌理”，不是旅游宣传风，不是互联网潮流风。整体应传达真实、缓慢、靠近土地与人的关系，强调在地经验、真实在场、路线节奏和人文温度。

```

## 15. 一句话结论

**野哉的设计不是把“旅行”做得更热闹，而是把“靠近土地与人物的真实过程”做得更有辨识度、更可信、更有温度。**
