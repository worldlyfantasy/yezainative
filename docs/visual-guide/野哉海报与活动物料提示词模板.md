# 野哉海报与活动物料提示词模板

> 用途：给图像生成、版式生成、设计 Agent、运营同学直接复用的实操模板。  
> 配套文档：`doc/野哉视觉规范.md`

## 1. 使用说明

这份文档不是品牌说明书，而是直接可复制的提示词模板。

建议使用方式：

1. 先阅读 `doc/野哉视觉规范.md`
2. 选一个最接近的场景模板
3. 替换其中的变量
4. 保留“负面约束”和“复核清单”
5. 如果是 AI 出图，先出 3 到 5 个方向，再收敛

## 2. 可替换变量

使用前先把下面这些变量填好：

| 变量 | 含义 | 示例 |
| --- | --- | --- |
| `{主题}` | 本次物料主题 | 阿坝高地徒步记录营 |
| `{副标题}` | 补充说明 | 与创作者一起用脚步和手帐认识高原地形 |
| `{场景}` | 发生地点或空间 | 川西高原草场与寺院之间 |
| `{对象}` | 面向谁 | 适合想慢下来、愿意记录的人 |
| `{关键信息}` | 时间/地点/人数/报名方式 | 4月12日-4月16日，限12人 |
| `{主视觉内容}` | 画面中的关键主体 | 逆风中的草场、行走中的旅人、手帐与地形 |
| `{传播渠道}` | 小红书/微信群海报/公众号头图/H5 | 小红书封面 |
| `{信息密度}` | 高 / 中 / 低 | 中 |
| `{动作}` | 希望用户做什么 | 报名、咨询、加入候补 |

## 3. 通用母提示词

适用于绝大多数野哉视觉物料。

```text
请为“野哉”生成一张{传播渠道}视觉物料，主题为《{主题}》。

品牌气质必须符合：在地田野感、编辑式叙事、土地肌理、真实在场、人文温度、节奏缓慢但不松散。不要做成旅游促销海报，不要做成互联网潮流海报，也不要做成度假产品广告。

视觉方向：
- 像一本关于土地、人物与路线的当代田野杂志
- 像一张有旧印刷感的招募海报
- 像一个认真做路线与内容的在地组织

配色要求：
- 主色使用暖米纸色、深土黑、灰褐、赭红、焦橙
- 推荐色：#F2E6C9、#2B241D、#6A5A4B、#993921、#D15E14
- 允许少量浅金、浅棕、纸白过渡

字体与排版要求：
- 标题是中文宋体气质，正文克制清晰，引语可少量楷体
- 版式偏编辑式，不要标准电商卡片风
- 允许局部斜向色带、轻颗粒、纸张纹理、印刷磨损感
- 信息结构清楚，阅读顺序明确

图像要求：
- 画面主体为：{主视觉内容}
- 场景要体现：{场景}
- 强调人与土地、路线、观察、停留、记录的关系
- 更像纪录片现场，不像摆拍游客照

文案信息：
- 主标题：{主题}
- 副标题：{副标题}
- 面向对象：{对象}
- 关键信息：{关键信息}
- 目标动作：{动作}

输出要求：
- 先给 3 个不同方向的视觉方案关键词
- 再给最终推荐方案的完整设计描述
- 最后给适合 AI 出图/排版工具的成品提示词
```

## 4. 负面提示词

下面这段建议无论哪个场景都附带：

```text
负面约束：
- 不要蓝紫色、霓虹色、赛博感、科技感
- 不要旅游促销风、景点宣传册风、度假村广告风
- 不要高饱和蓝天草地和网红打卡感
- 不要厚重圆角卡片、玻璃拟态、大面积发光渐变
- 不要把人物处理成摆拍游客照
- 不要使用“爆款、必打卡、治愈一切、说走就走、高级感拉满”这类文案
- 不要把品牌做得过于小资、甜美、悬浮
- 不要过满排版，不要信息挤成电商促销图
```

## 5. 场景模板

## 5.1 招募海报

适用于路线招募、活动招募、驻留计划、开放报名。

```text
请为野哉设计一张“招募海报”，主题为《{主题}》。

画面要像一张当代田野招募海报，而不是旅游团促销海报。主视觉聚焦 {主视觉内容}，强调真实、在地、节奏与土地关系。整体像暖米纸上的编辑排版，带轻微印刷颗粒与旧海报肌理。

标题用中文宋体，放大处理。辅助信息采用克制无衬线。主标题与画面之间可以有轻微错位、叠压或斜切结构，但阅读顺序必须清楚。

必须包含信息：
- 标题：{主题}
- 副标题：{副标题}
- 时间/地点/人数：{关键信息}
- 面向对象：{对象}
- 行动指令：{动作}

色彩保持在暖米纸色、赭红、深土黑、焦橙范围内。画面重点不在“美景”，而在“靠近一条路线、一个地方和一群人”的真实感。
```

## 5.2 活动主视觉 KV

适用于首页头图、H5 首屏、公众号头图、活动专题封面。

```text
请为野哉设计一张“活动主视觉 KV”，主题为《{主题}》。

定位不是广告促销图，而是具有品牌辨识度的内容主视觉。画面需要强视觉重心，但不过度热闹。可以使用大面积留白、一处高质量在地图像、赭红标题、轻斜向结构和纸张纹理。

画面重点：
- 主体：{主视觉内容}
- 情绪：缓慢、真实、靠近、旷野、人文
- 场景：{场景}

信息层级：
- 第一层：标题《{主题}》
- 第二层：副标题 {副标题}
- 第三层：必要信息 {关键信息}

请做出“像一本田野杂志封面”的感觉，而不是“像旅游 App banner”。
```

## 5.3 小红书封面

适用于内容预告、路线推荐、活动预热。

```text
请为野哉设计一张“小红书封面”，主题为《{主题}》。

封面要保留野哉的土地感与品牌辨识度，但同时适配小红书的信息读取方式。不要做成网红旅游封面，不要使用过多大字堆满整版。

要求：
- 只突出一个核心信息点
- 主标题控制在 1 到 2 行
- 画面主体必须真实、不摆拍
- 可以加入赭红 Logo 或品牌字样，但不要压过内容
- 颜色必须保持暖米、赭红、深土黑、焦橙体系

标题建议：{主题}
补充信息建议：{副标题}
封面气质：纪录感、在地、克制、有温度
```

## 5.4 社群传播长图

适用于微信群、朋友圈长图、活动报名说明长图。

```text
请为野哉设计一张“社群传播长图”，主题为《{主题}》。

整张图像一篇被设计过的说明文档，而不是单页促销图。版式上采用上标题、中图像、下信息分段的编辑式结构，用分割线、留白和浅纹理组织内容。

内容模块建议：
- 标题区：{主题}
- 引导语：{副标题}
- 适合谁：{对象}
- 活动信息：{关键信息}
- 报名方式：{动作}

图像应服务于说明，不要为了视觉而牺牲阅读效率。整体气质仍需符合野哉：在地、真实、缓慢、人文、纸张感。
```

## 5.5 路线详情页首屏

适用于 H5、详情页、专题页首屏视觉。

```text
请为野哉设计一张“路线详情页首屏”，主题为《{主题}》。

目标是让用户第一屏就理解这条路线的气质，而不是先感到花哨。画面要同时满足品牌感和转化效率：有强视觉重心、有宋体标题、有摘要、有清晰行动入口，但不出现旅游电商式吵闹结构。

必须表达：
- 这是什么路线：{主题}
- 它为什么值得去：{副标题}
- 它发生在什么场景：{场景}
- 它适合谁：{对象}
- 下一步动作：{动作}

视觉可参考当代杂志开页：大图、重标题、留白、细分割线、浅颗粒、土地色。
```

## 5.6 故事内容封面

适用于文章封面、故事专题、人物记录内容。

```text
请为野哉设计一张“故事内容封面”，主题为《{主题}》。

这不是景点封面，而是一篇关于土地、人物、路线、在地经验的记录型内容封面。请突出内容感和阅读感，像一本田野杂志文章首页。

要求：
- 图像有纪录片现场感
- 标题是宋体大字，位置克制
- 摘要少量出现，不要喧宾夺主
- 颜色偏纸感、灰褐、赭红
- 可加入引语式短句，但不要鸡汤
```

## 6. 文案生成模板

如果要让 AI 同时帮你写标题和副标题，可以套下面的格式。

### 6.1 海报标题模板

```text
请围绕主题“{主题}”，为野哉写 10 个海报标题。

要求：
- 保留野哉的在地、人文、路线、真实在场气质
- 不要广告口号，不要鸡汤，不要网红文案
- 更像一本田野杂志的标题，而不是促销 slogan
- 每个标题控制在 8 到 18 个字
```

### 6.2 招募副标题模板

```text
请为野哉的《{主题}》写 10 个副标题。

要求：
- 用一句话说明这是什么、为什么值得参与
- 要具体，不要空泛抒情
- 可以包含“在地、节奏、记录、土地、旅人、创作者”等词
- 不要出现“治愈、爆款、秘境、打卡、逃离城市”
```

### 6.3 适合谁文案模板

```text
请为野哉的《{主题}》写一段“适合谁”说明。

要求：
- 真实、直接、克制
- 帮助用户做判断
- 不要讨好所有人
- 语气要像认真负责的路线说明，而不是营销文案
```

## 7. 给设计 Agent 的结构化任务模板

适用于让 AI 直接产出设计方案，而不是只写一句 prompt。

```text
请作为资深品牌设计师，为“野哉”完成一版 {传播渠道} 视觉方案，主题是《{主题}》。

先输出以下内容：
1. 设计目标
2. 目标受众
3. 视觉方向关键词
4. 色彩方案
5. 字体与层级方案
6. 版式结构草案
7. 图像建议
8. 文案排布建议
9. 明确禁忌
10. 最终可复制 prompt

品牌必须符合：
- 在地田野感
- 编辑式叙事
- 土地肌理
- 真实在场
- 人文温度
- 不模板化
- 不旅游促销风
```

## 8. 快速组合公式

如果时间很赶，可以直接套这个一句话公式：

```text
为野哉设计一张{传播渠道}物料，主题《{主题}》，主视觉是{主视觉内容}，场景发生在{场景}，整体气质像当代田野杂志封面与旧印刷招募海报的结合，使用暖米纸色、赭红、深土黑、焦橙，标题为中文宋体，版式克制、留白充足、带轻颗粒和纸张纹理，强调真实在场、在地经验和路线节奏，不要旅游促销风，不要网红打卡风，不要蓝紫霓虹，不要厚重电商卡片。
```

## 9. 出图后复核清单

无论是 AI 还是设计师产出，最后都用这份清单检查：

- 是否一眼看上去更像“在地内容品牌”，而不是“旅游销售海报”
- 是否用了暖米、赭红、深土黑、焦橙这条色线
- 是否有纸张、印刷、颗粒、土地这类质感
- 是否有足够留白和阅读顺序
- 是否避免了蓝紫、霓虹、科技风
- 是否避免了网红打卡旅行图
- 是否文案具体、有对象、有场景，而不是空泛抒情
- 是否兼顾品牌感与信息清晰度

## 10. 推荐工作流

最稳妥的方式：

1. 先把 `doc/野哉视觉规范.md` 作为系统上下文
2. 再把本文件中的某个模板作为任务输入
3. 最后补充本次活动的具体信息与限制

如果需要连续出多张图，建议固定这三层输入不变：

- 第一层：品牌规范
- 第二层：场景模板
- 第三层：本次活动变量

这样连续生成的物料风格会稳定很多。
